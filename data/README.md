# Dataset

Use BDD100K and RWVC-BDD100K.

BDD100K provides real-world road images/videos, object detection annotations and weather attributes including foggy. RWVC-BDD100K adds manually annotated visibility information to a 13.3K-image subset (8.8K train, 2.5K validation, 2K test).

Download from the dataset/research sources and place them under:
data/bdd100k/
data/rwvc-bdd100k/

Do not commit raw datasets to GitHub.
